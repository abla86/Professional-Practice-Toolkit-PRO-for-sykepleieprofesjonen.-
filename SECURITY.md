# Security Policy

## Current scope
This repository is an empty early scaffold. It has no implemented clinical workflow or approved health-data processing. Do not use it with real patient information or for clinical decisions.

## Reporting
Report suspected vulnerabilities privately through GitHub private vulnerability reporting if available. Otherwise contact the maintainer privately. Do not include patient data, credentials, tokens or other secrets in reports.

## Development safeguards
- Do not commit secrets, patient data or confidential employer information.
- Keep the development server bound to localhost unless external access is intentionally configured.
- Treat AI-generated clinical content as untrusted and require qualified review before any clinical use.
- Build success is not evidence of clinical safety, privacy compliance or production security.
